# 原厂硬件与90 W的实现依据

046已经接通并原生构建通过受限的PPS后端：MCA2101a请求9V/2A，2101c和两组新电压确认后FCC≤1500mA，退出须测得5V后恢复原USB-OVP，泵保持关闭。人类暂时不方便原装100W换线配合，真实PPS和新ADC退场仍待本次上机。047继续补原厂SC8585故障的实际消费者：完整寄存器读数和首次状态读数进入解码器，硬件故障阻止PPS/升流发包并触发原有降流和5V恢复；PM失效同步撤回保护读数的有效标志。SC8585的倍率、保护阈值、独立故障位和定时配置已与本机OS4模块核对，未开启直充。

SC8585与SC8581的BUS_OVP/OCP步长及IBAT/TSBAT支持不同，不能混用。实存0D28的看门狗低三位为0，软启动时限为5120ms；定时配置和setter ACK均不证明到期后CHG_EN关断。OS4切倍率会设置整组保护且漏传I2C写错误，不能只复制模式位或把其返回0当硬件确认。现有故障路径是软件响应，完整开路、CC/CV、FFC和自主失联关断仍待接续与真机验证。

**90 W尚未实现或实测。** 025已在原装100W同次启动两轮通过新认证、固定9V/FCC1500及恢复5V/OVP；027被动worker PM已通过。031的14次ITERM读回均为零，032b/033分别完成主连接器、QTM/GPIO恢复及启动日志。已捕获当前SoCCP固件证明ITERM/FCC getter没有实现；034因此保留固件ITERM，只接管可读回的ICL/FV/启停与电流反馈FCC，并修正同适配器PM恢复后的重新认证。034原生及全部14项电脑资格已通过；随后固件证明ICL为HLOS Min聚合缓存，035补正值100票保留、有效零值、较低预算不重发和ACK丢失处理，独立停用确认保持。035受影响宿主路径已通过，目标和正常5V/活跃PM硬件结果另验。

已取得的正面依据：

- 本机原厂FDT启用MCA/PD/quickchg，PD class `max_power=90`。
- quickchg有 `support_mode=6`、`max_vbat=4490mV`、最高15600mA的电池侧限流表，以及ATL/LWN分别配置的温控/电压表。
- 充电路径包括PMIH010x主充电器、SC8585、bq27z561及测温/保护链；SOCCP提供MCA和PD操作。HL7606实际属于显示boost/bypass，由显示组件管理。
- 公开nezha原厂模块确认PPS请求/状态、PDO长度与真实计量属性，证明主机有标准接口可接续。
- piano已提供一个接近原厂MCA的主机策略参考：认证期间不升压、读取APDO、先核泵关闭、设置保护、请求PPS、测量确认、软启动、调节与退出。它的实测范围不能转算为nezha能力。

这些依据尚未证明具体配件上的本机90 W合同和曲线。SC8585支持4:1等模式，但本机不同阶段实际选择哪个模式、
泵与buck如何分流仍须当前模块/原厂正常充电日志互证；不由寄存器能力猜默认配置，不接管显示HL7606。

`NpChargePolicy` 消费外部已验证的profile、认证、限值和保护状态；它只生成一次性动作，
收到相应epoch/request-ID回执后推进；过期/远端换代/热限制变化即停止推进，先确认泵关断再释放本方票据。
它**不是**原厂quickchg算法或完整充电控制器。没有硬件执行后端，不能把动作枚举、verified字段或PPS编码器当完成功能。

优先移植原厂策略需要补齐：

1. 当前OS4相关模块已本地取得并核SHA；继续核batterysecret/HAL的真实执行顺序和本次附件认证，不用OS3符号代替OS4合同。
2. 全部有效温度来源：电池、pack热敏、connector、PMIC、pump die及传感器失效行为。
   选择真实电池供应商的JEITA/FFC/温控投票及回差，不能混用piano或sheng阈值。
3. BC1.2/Type-C/PD/UCSI协调和所有权，wireless/OTG互斥；认证/角色变更不得抢USB调试或复用旧attach的认证成功。
4. 验证硬件自主OVP/OCP/OTP和失联关断。不能依赖USB日志线程或普通轮询一直存活来保证高功率安全。
5. 同机原厂安卓基线：相同适配器、原厂线、可比SOC/温度/负载、测点一致的输入/电池功率和温度曲线。

90 W验证记录必须分别列出：适配器额定值、协商档位、USB入口实测、SC8585/PMIC分支、电池净充入及系统负载。
当前MCA的两个独立GET不满足同时采样要求，因此不会发布“实测USB功率”。
真正测试用兼容私有协议的功率计或有锁存/时间同步依据的采样，保存峰值及持续时间、稳态、热降档和充满回充。
电脑USB线、hub或普通功率计不能默认维持原厂协议；测试日志需有脱离USB后仍有效的既有log/本地采样出口。
